AVATAR BENDING @VERSION@  -  Minecraft 1.21.1 (Fabric)
=====================================================

50 bending spells (10 for each element + 10 Avatar spells), custom sounds,
glowing effects and the Avatar State.

This zip contains:
  overrides/mods/avatarbending-@VERSION@.jar          <- the Avatar Bending mod
  overrides/mods/fabric-api-@FABRIC@.jar   <- Fabric API (required)
  manifest.json                                   <- lets launchers import the zip as a modpack


INSTALL WITH SKLAUNCHER
-----------------------
1. Open SKLauncher and go to the "Installations" tab.
2. Click "New installation".
3. Under "Version", pick  Fabric  and  1.21.1  (any loader version 0.16 or newer).
   Click Save.
4. Open your mods folder:
     Windows:  press Win+R, type  %appdata%\.minecraft\mods  and press Enter
     macOS:    ~/Library/Application Support/minecraft/mods
     Linux:    ~/.minecraft/mods
   (Create the "mods" folder if it does not exist. If your installation uses its own
   game directory, use the "mods" folder inside that directory instead.)
5. Open this zip, go into  overrides  ->  mods  and copy BOTH .jar files into the
   mods folder from step 4.
6. Select the Fabric 1.21.1 installation in SKLauncher and press Play.

UPDATING FROM AN OLDER VERSION: delete the old avatarbending-1.0.0.jar from your
mods folder first. Two copies of the mod in the same folder stop the game from starting.

Tip: if your launcher has an "Import modpack" button (SKLauncher 4, Prism Launcher,
CurseForge, MultiMC...), you can import this zip directly instead of steps 4-5.

Remove any other copy of Fabric API for a different Minecraft version from the
mods folder, or the game will refuse to start.


HOW TO PLAY
-----------
When you join a world, a screen asks you to choose your element: Air, Water, Earth or Fire.

  R  = Bend (use the selected spell)
  G  = Next spell        (Shift + G = previous spell)
  K  = Bending Scroll: see every spell and click one to select it
  V  = Switch element    (only the Avatar)
  B  = Avatar State      (only the Avatar)

The small HUD next to your hotbar shows the selected spell, your Chi bar and one
dot per spell (white = selected, dark = recharging). Every spell costs Chi, which
refills by itself. You can change the keys in
Options -> Controls -> Key Binds -> Avatar Bending.

BECOME THE AVATAR
Craft the Avatar Spirit in a crafting table:

        [          ] [ Breeze Rod  ] [            ]
        [Heart of  ] [ Totem of    ] [ Diamond    ]
        [the Sea   ] [ Undying     ] [ Block      ]
        [          ] [ Blaze Rod   ] [            ]

Right-click with it to master all four elements, unlock the 10 Avatar spells
and the AVATAR STATE (press B): flight, a four-element aura that blasts enemies
away and turns arrows around, free spells and 75% more power for 30 seconds.
Avatar's Wrath can only be used in the Avatar State.

Cheats/creative: /bending avatar  makes you the Avatar instantly.
Other commands: /bending info, /bending choose <element>, /bending reset,
/bending set <player> <element>, /bending refill, /bending cast <spell>.

Screen shake and flashes follow the "Distortion Effects" and "Hide Lightning
Flashes" settings in Options -> Accessibility Settings.
